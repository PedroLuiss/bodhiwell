# Bodhiwell Design System — paquete esencial

Este paquete conserva únicamente lo necesario para navegar y consultar el manual.

## Recorrido recomendado
1. `start-here.html`
2. `foundation/`
3. `patterns/` y `examples/`
4. `assets/` y `components/` como soporte

## Estructura
- `foundation/`: documentación base del sistema
- `patterns/`: pantallas y recorridos principales
- `examples/`: referencias aisladas y validaciones visuales
- `components/`: piezas reutilizables
- `assets/`: estilos, imágenes y recursos compartidos

Se eliminaron archivos de auditoría, revisiones puntuales, changelogs operativos y scripts auxiliares para dejar una entrega más limpia.
