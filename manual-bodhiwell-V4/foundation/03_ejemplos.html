El blog pasa a formar parte de los ejemplos oficiales del sistema junto a la landing, con home editorial y página de artículo como referencias implementables. Se incorporan además las nuevas referencias de Perfil público edición y Datos personales como ejemplos oficiales del flujo de configuración profesional.

Cómo usar estas pantallas

Cada ejemplo está pensado como referencia implementable: layout, spacing, tipografía, íconos y estados. La referencia vigente para jerarquías de títulos y uso de eyebrow es la landing oficial y el blog oficial. Usar examples para piezas aisladas y patterns para páginas o módulos ya integrados.
