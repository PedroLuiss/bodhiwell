02 Componentes base

Reglas aplicables para desarrollo. Esta página reúne variantes aprobadas, estados obligatorios y ejemplos vivos para validar comportamiento visual. Además, fija los radios oficiales del sistema para evitar resoluciones intermedias no previstas.

03.0 Eyebrow

La eyebrow funciona como rótulo introductorio de sección. Sirve para anticipar el tema del bloque antes del H1 o H2, ordenar la lectura y dar contexto sin competir con el título. En Bodhiwell se usa alineada al mismo arranque del título, nunca como un prefijo separado por guiones, líneas o espacios manuales.

Regla aprobada

Comunidad

Profesionales que acompañan con propósito

Reglas de estilo
  • Se coloca siempre encima del título y con el mismo arranque visual del H1 o H2.
  • Usa mayúsculas, tracking amplio y color Primary. No usa guiones iniciales, líneas decorativas ni sangrías manuales.
  • Se aplica en aperturas de bloque, héroes editoriales y módulos como comunidad, blog o glosario cuando ayuda a introducir el contenido.
  • No reemplaza tags, pills ni labels funcionales.
  • Separación recomendada respecto al título: 12–18px abajo, según la escala del bloque.

03.1 Botones — (inline)

Regla: máximo 1 Primary por pantalla. Radio oficial del control: 16px.

Ejemplo (inline)

Estados obligatorios (no libre decisión)
  • Primary: Default — --bw-primary · Hover — --bw-primary-hover · Active — --bw-primary-active · Disabled: opacity.
  • Secondary (outline): Hover/Active por tinte (background) — no crear un “primary 2”.
  • Ghost: Hover/Active con neutros suaves.

03.4 Carga y recorte de imagen

Componente para cargar una foto, producir una salida horizontal para perfil, una salida vertical para tarjeta y revisar el resultado antes de guardar. La documentación se compacta para mostrar el flujo real sin reiteración.

Referencia principal del flujo
La pantalla de revisión final reúne las dos salidas y es la referencia principal para validar cards, radios, tipografía y CTA de guardado.

Síntesis operativa

Este componente se documenta con sus siete estados reales: estado vacío, modal de carga, selector de archivo, recorte 16/7, recorte 4/5, revisión final y estado con imagen aplicada.

--bw-card-surface · #F7F5F1 modal, revisión final y contenedores principales.
--bw-card-surface-soft · #F8F6F2 soportes internos y superficies secundarias.
  • Tipografía declarada en HTML y CSS con Sora y font-style: normal.
  • El CTA sobre imagen usa fondo blanco translúcido, borde sutil y blur leve.
  • La portada usa relación 16/7 y la tarjeta 4/5.
  • Accesibilidad mínima: role="dialog", aria-modal="true", tecla Escape y bloqueo de scroll.
