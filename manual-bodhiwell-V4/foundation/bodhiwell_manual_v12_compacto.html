Foundations

Identidad del sistema

Color, spacing, radius y sombras definen el “ritmo” visual de Bodhiwell.

01.1 Spacing (8px system)

Usar la escala. Evitar valores arbitrarios.

--bw-space-14px · micro
--bw-space-28px · mínimo
--bw-space-316px · estándar
--bw-space-424px · bloques
--bw-space-532px · secciones
--bw-space-648px · bloques grandes
--bw-space-764px · hero
Regla (estados)
  • Hover / Active nunca se definen “a ojo”.
  • Primary: --bw-primary (#82B194) → --bw-primary-hover (#739F84) → --bw-primary-active (#5C826C).
  • Disabled: solo opacidad (sin cambiar el color base).

01.2 Radius

Bordes suaves (calma). Botones fijados a 16px.

--bw-radius-sm8px · inputs
--bw-radius-md16px · buttons (LOCK)
--bw-radius-lg16px · cards
--bw-radius-xl22px · containers

Components

Componentes

Botones, chips y tipografía (LOCKED).

03.1 Botones — (inline)

Regla: máximo 1 Primary por pantalla.

Ejemplo (inline)

Radio de botón: 16px (LOCK).

Estados obligatorios (no libre decisión)
  • Primary: Default --bw-primary · Hover --bw-primary-hover · Active --bw-primary-active · Disabled: opacity.
  • Secondary (outline): Hover/Active por tinte (background) — no crear un “primary 2”.
  • Ghost: Hover/Active con neutros suaves.
