01 Tokens del sistema

Base visual para implementación: colores, tipografía, espaciados y sombras. Esta página es la referencia única para el equipo de desarrollo al construir componentes nuevos.

Regla de color UI: el sistema usa tres niveles de texto y dos acentos principales. --bw-text para títulos, cuerpo y acciones prioritarias; --bw-text-secondary para subtítulos y ayudas; --bw-text-tertiary para footer y placeholders; --bw-primary como acento principal y --bw-gold como acento complementario para recorridos, hitos y estados destacados.
