Manual de uso y sistema de diseño

Introducción

Organizar la diversidad del bienestar bajo una estructura clara, responsable y humana.

Bodhiwell integra distintos enfoques dentro de una arquitectura común, priorizando claridad, coherencia y una experiencia comprensible para el consultante.

El sistema organiza la complejidad profesional para que la experiencia del consultante sea simple.

Principio rector Bodhiwell
Claridad para el consultante

La estructura debe ayudar a comprender quién es el profesional, desde qué enfoque trabaja y qué herramientas complementarias utiliza.

Integración sin jerarquías

Las dimensiones funcionan como guía de navegación. No establecen superioridad entre enfoques.

Coherencia profesional

La profesión principal se define desde la formación base y las especialidades amplían el perfil sin reemplazarlo.

Escalabilidad estructural

El sistema fue pensado para crecer y mantener el orden sin rediseñar su arquitectura.
