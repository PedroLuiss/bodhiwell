Cómo usar este manual

Esta sección ayuda al equipo de diseño y desarrollo a usar el sistema de forma consistente. La idea no es solo leer reglas: es saber en qué orden recorrer la documentación y cómo aplicar lo definido sin abrir variaciones innecesarias.

1. Empezar por el recorrido correcto

Antes de diseñar o desarrollar una interfaz nueva, recorrer el manual en este orden: Concepto, Tokens, Componentes, Cómo usar y Base oficial. Ese recorrido evita decisiones aisladas y ayuda a entender qué está definido y qué puede variar.

  • Empezar por Concepto para entender la lógica del sistema.
  • Seguir por Tokens y Componentes antes de abrir una pantalla nueva.
  • Validar la estructura final en Base oficial antes de implementar.

2. Usar tokens y componentes antes de crear variantes

Antes de crear un componente nuevo, revisar si ya existe una solución equivalente en el sistema. El objetivo es mantener consistencia visual y reducir complejidad técnica.

  • Inputs, botones, tags y cards deben reutilizarse.
  • Los estados deben respetar la lógica definida.
  • Los ajustes nuevos deben documentarse.

3. Validar con examples y patterns reales

Los ejemplos no son decorativos: muestran cómo se aplican las reglas en situaciones reales del producto Bodhiwell. Los patterns, además, funcionan como referencia estructural de páginas completas ya integradas.

  • Buscador inteligente
  • Grid de profesionales
  • Perfil profesional
  • Agenda / booking
  • Dashboard, header y footer
  • Landing, blog y buscador como patterns integrados
Regla práctica: si una nueva pantalla puede resolverse reutilizando tokens, componentes y base oficial ya definidos, esa es la opción correcta. Solo conviene abrir una variante nueva cuando exista una necesidad funcional real y esa variante quede documentada.
